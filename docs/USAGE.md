## 食材登録

ホームの「食材を追加」から、名前・残量・単位・期限・保存場所を登録します。食材名に応じて画像や入力値を補完しますが、期限は目安です。パッケージの表示を確認してください。

画面上部で表示名・期限日・残量を確認し、単位・保存場所・レシピ用分類を調整します。写真・カテゴリ・購入日・メモは「写真・カテゴリ・購入日・メモを編集」から開きます。閉じても入力内容は保持します。

| 項目 | 使い分け |
| --- | --- |
| 商品名・表示名 | 一覧で商品を見分けるための名前。例：明治おいしい牛乳 |
| レシピ用分類 | 材料の照合に使う名前。例：牛乳 |
| 保存場所 | 冷蔵・冷凍・常温 |
| 残量と単位 | 個・g・ml・本・袋・パック。例：1000ml |
| 期限日・購入日 | 今回購入した商品の情報 |
| メモ・写真 | 自分用の補足情報 |

写真は撮影またはライブラリから選べます。初回は端末でアクセスを許可してください。写真は1枚5MBまでです。選択に失敗した場合は元の写真を残し、選び直せます。表示できない画像は「写真なし」と表示します。

### 同じ食材をもう一度登録する

1. 「食材を追加」→「前の登録から選ぶ」、または食材詳細の「もう一度登録する」を開く。
2. 今回の購入量を入力し、期限を確認する。
3. 保存すると、元の履歴を残したまま新しい在庫が作られる。

前回の名前・保存場所・単位などを引き継ぎます。前回の残量・期限・メモ・写真は、新しい購入分へそのままコピーしません。今回の購入量は入力し直し、期限を確認してください。

## ホームとカレンダー

ホームでは、名前・商品名・レシピ用分類・タグで検索し、「期限順」「保存場所別」「カテゴリ別」に表示できます。

上部の「今日まで」「明日〜3日以内」は、在庫全体の登録件数です。期限切れ・使用済み・廃棄済みは含めません。「この食材でレシピを探す」から、期限が近い食材を使う料理へ進めます。

期限切れがある場合は、最上部に件数と「確認」ボタンを表示します。押すと検索を解除して期限切れだけを表示し、「すべての食材に戻す」で解除できます。食べられるかどうかを判定する表示ではありません。

カレンダーは日付ごとの食材を表示します。選んだ日を期限にして食材を追加したり、期限を変更したりできます。「今日に戻る」で当月・当日に戻ります。期限の判定は日付変更時とアプリ復帰時に更新します。

月の一覧には食材の件数を表示します。日付を押すと下の一覧で商品名・残量を確認できます。

## バーコード登録

1. バーコードタブを開き、カメラの使用を許可する。
2. 商品のバーコードを枠内に映す。JAN/EANは番号を入力して検索することもできる。
3. 取得した商品名・分類・取得元を確認して、登録画面へ進む。
4. 今回の期限・購入日・保存場所・数量を確認して保存する。

同じコードの連続読み取りは停止します。「もう一度読み取る」で再開できます。商品が見つからない場合は、番号を引き継いで手入力できます。

検索順は **端末で学習した商品 → サンプル（デモ設定時のみ） → 共有商品DB → Yahoo!ショッピング → Open Food Facts** です。オンライン検索には通信が必要で、未設定の検索先は使いません。共有DBの障害時も外部検索へ進みます。

バーコードから期限・購入日・保存場所・数量は取得しません。登録画面で修正した分類は端末に学習し、次回同じ番号を読むときに優先します。

登録済みの商品名や分類は、食材詳細の「この食材を編集」から訂正できます。「次回のスキャンにも商品名・分類を反映」を選ぶと、この端末の商品候補も更新します。期限・残量・保存場所・メモは候補に反映せず、共有商品DBへの送信も行いません。今回の在庫だけを直したい場合はチェックを外してください。

商品名を訂正すると、一覧や詳細にもその名前を表示します。「米」と「ごはん」、「牛乳」と「プリン」などはレシピ用分類を分けます。分類を特定できない商品は、登録時に分類を確認してください。自動入力の保存場所も候補なので、パッケージの保存方法を優先してください。

### 商品情報を共有する

外部検索でも見つからず手入力した商品では、接続先の設定後に「投稿ルールに同意して、この商品情報を共有する」を選べます。初期状態はOFFです。投稿ルールと4項目を確認してください。送る商品情報は **バーコード・商品名・レシピ用分類・カテゴリ** だけで、在庫・写真は送りません。サーバーにはルールの版・受付／審査日時も記録します。管理者の確認後に検索できます。

共有の通信に失敗しても、食材の登録と共有は別に扱います。完了画面から共有だけを再試行でき、食材は重複登録しません。

共有の商品検索結果に問題があるときは「この商品情報を通報する」から理由を選んで送信できます。バーコードと理由だけを送り、管理者が確認します。通報だけで商品が自動で非公開になるわけではありません。「共有情報を使わずに手入力」なら、商品名などを引き継がずに登録できます。

共有対象は有効な8桁・13桁のJAN/EANです。店舗用コードなど一部の番号や、外部サービスから取得した商品情報は共有対象外です。詳しくは [共有商品DB](../server/README.md) を参照してください。

## レシピ

料理の写真・名前・調理時間・使える食材から選べます。「絞り込み」で条件やカテゴリを指定し、各料理の「確認」で材料と不足分を開きます。自作レシピの追加・編集・削除、お気に入りにも対応しています。

### 材料と在庫を確認する

| 表示・条件 | 意味 |
| --- | --- |
| 材料の一致率 | 材料の種類がそろう割合。分量が足りることは保証しない |
| 分量あり | 登録された分量まで足りるレシピ |
| 買い足し | 在庫がない、または数量が足りない材料がある |
| あと○○必要 | 必要量と使える在庫を比較した不足量 |
| 要確認 | 適量・少々、単位の違いなどで自動比較できない |

同じ食材・同じ単位の在庫は合算し、期限切れ・使用済み・廃棄済みは除外します。材料はレシピ用分類と明示した表記ゆれで照合します。検索タグや単なる部分一致は使いません。分類が広すぎる場合は、食材登録画面で修正してください。

初期レシピと端末内の提案レシピには、調味料・炒め油も含めています。調理用の「水」は材料表に表示しますが、一致率・不足量・買い物追加・使用量記録からは除きます。「ミネラルウォーター」など別名の材料は通常どおり照合します。

### 人数に合わせて分量を変える

レシピの追加・編集では「分量の基準」に1〜99人分を設定できます。空欄は人数未設定です。

詳細の「作る人数」を変えると、材料表・不足量・使用量の提案が変わります。閲覧中の人数変更は、保存したレシピの基準人数や分量を書き換えません。

- 分数や「大さじ1と1/2」、対応する単位を換算します。
- 「適量」「少々」はそのまま表示します。
- 「2〜3個」「1個（約200g）」などは「元の分量・要確認」と表示します。
- 手順の文章と加熱時間は変わりません。

### 不足材料を買い物へ追加する

「買い物の準備」から、在庫がない材料や数量が足りない材料を追加できます。選んだ人数・不足分・必要量・在庫量をメモに残します。

調理用の水と、すでに未購入リストにある同名の材料は追加しません。既存メモも上書きしません。換算できない分量は「要確認」と明記します。

### 調理後に使った量を記録する

購入した在庫ごとに、期限・保存場所・現在の残量を表示します。「使った分を自動選択」は、分量が足りる材料について期限が近い在庫から使用量を割り当てます。牛乳が100mlと200mlあり、200ml使用する場合は、先期限の100mlを使い切り、次の在庫に100mlを残します。

「変更なし」「使用量を入力」「使い切る」で調整し、表示された使用後の残量を確認して記録します。分量不足・適量・換算できない単位は実際の使用量を入力してください。必要量を満たした後の在庫は自動選択しません。「全部使い切る」は表示中の全在庫を使い切る操作です。

作る人数を変えると使用量の選択は解除されます。確認中に在庫が編集・削除された場合や期限を過ぎた場合は、全件の更新を中止して選び直します。同じ確定操作の連打では二重に減りません。使い切った食材は買い物リストへ追加できます。

食材詳細の「調理での使用履歴」で、使用量と当時の残量を確認できます。使用履歴はバックアップにも含まれます。使い切りの「記録を取り消す」は直前の残量で管理中に戻し、それ以前の部分使用量は戻しません。履歴は操作の記録として残ります。

「もっと探す」から開くクックパッド連携は、外部の検索ページへのリンクです。レシピ本文や画像をアプリに取り込む機能ではありません。

## 買い物リスト

- 「買うもの」に入力するか、「よく買うもの」の候補から追加します。
- チェックで購入済みにします。画面上部の「買うもの」「購入済み」で一覧を切り替えます。食材登録前ならチェックを外して未購入へ戻せます。
- 購入済みの「食材を登録」から、名前・メモを引き継いで在庫を登録できます。購入量はフォームで指定します。登録後は「登録済み · 食材を確認」に変わり、同じ購入分からの二重登録を防ぎます。
- 登録済みの購入分は未購入へ戻せません。次の購入は新しい項目として追加してください。
- 「卵／たまご」「醤油／しょうゆ」など、対応する表記揺れも含めて未購入の重複を防ぎます。ブランドが異なる商品や「米／ごはん」などは別項目です。
- 「よく買うもの」は、関連付けた購入済み項目と登録食材を二重に数えません。過去の関連付けがない記録は推測で統合しません。
- ごみ箱を押すと確認が開き、「削除する」で削除します。

買い物項目を削除しても登録した食材は残ります。食材を完全削除した場合は、その購入分の登録済み表示も解除されます。使用済み・廃棄済みの記録が残っている間は、登録済みとして扱います。

## 使い切り・廃棄と統計

食材詳細のボタン、またはホームのカードのスワイプで記録します。**左へスワイプで「使い切った」、右へスワイプで「捨てた」** の確認が開きます。キャンセルした場合は記録しません。

ホーム左上や設定から統計を開き、「今月」「先月」「全期間」の件数・比率・履歴を確認できます。記録を取り消すと、管理中の食材に戻ります。廃棄ランキングから、買い物リストへ注意メモを付けることもできます。

食材ロス率は `捨てた数 ÷（使い切った数 + 捨てた数）× 100` です。記録がない場合は `0.0%` と表示します。

「削除する」は履歴に残らない完全削除です。使い切り・廃棄の記録とは異なります。

## 期限通知

1. 設定タブで通知日を入力し、「追加」で登録する。`0日前` は期限当日。
2. 通知時刻を決め、「通知設定を保存」を押す。
3. 端末の通知を許可し、「3秒後にテスト通知」で確認する。

通知日は複数設定でき、チップを押すと削除できます。食材の追加・編集・削除に合わせて予約を更新し、通知をOFFにして保存すると予約を解除します。

保存完了は、設定の保存と端末の通知予約の更新が終わってから表示します。失敗した場合は画面に理由が表示されるので、「通知を再同期」で再試行してください。アプリに戻ったときも権限・現在の時刻帯・在庫に合わせて予約を確認します。通知権限を端末の設定で変更した場合も、アプリに戻って状態を確認してください。

通知を押すと対象食材の詳細へ移動します。削除済みの場合はホームへ戻ります。権限と予約件数は設定画面の「通知の状態」で確認できます。実際の通知動作はスマートフォンで確認してください。

**Web版では期限通知を利用できません。** 通知の設定・保存・テストはスマートフォンで行ってください。

## バックアップと復元

1. 設定タブの「データ管理」から「バックアップを書き出す」を押す。
2. 容量・重複を除いた写真枚数・外部画像の件数を確認し、「保存する」でJSONファイルを保存する。
3. 復元先の端末で「バックアップから復元」を押し、ファイルを選ぶ。
4. 作成日時・件数を確認し、「復元する」を押す。

**復元すると現在の主要データが置き換わります。先に現在のデータを書き出してください。**

食材・履歴・買い物・通知設定・レシピ・端末で学習した商品を保存します。端末の写真はファイルに含め、同じ画像は1枚にまとめます。写真は1枚5MB、重複を除いた合計10MB、JSONファイル全体は20MBまでです。上限を超えた場合は小さい写真に選び直してください。

アプリに付属するレシピ画像は復元先の同梱画像を使います。外部サイトの商品画像などはURLを保存し、画像そのものは含めません。表示には通信が必要で、公開元で削除された画像は「写真なし」と表示します。

書き出し形式はv2です。このバージョンでは従来のv1も読み込めますが、v2は古いアプリで読み込めません。復元先も更新してください。通知権限は端末固有なので含めず、復元後に通知予約を作り直します。通知の再同期だけが失敗した場合は、復元されたデータを保持したまま再試行できます。

変更内容と実機での確認手順は [Phase 3の変更と実機確認項目](phase3-notifications-backup.md) にまとめています。

共有商品DBのバックアップは別途サーバーで行います。[管理・運用の手順](../server/README.md)を参照してください。

### 端末内の保存データをまとめて削除する

設定の「この端末の保存データを削除」から「削除する内容を確認」を選びます。対象を確認し、必要なら先にバックアップを書き出してください。「削除」と入力して削除ボタンを押すと開始します。開始後は取り消せません。

食材と履歴、買い物、自作レシピ・お気に入り、設定、商品候補、復元前の退避、アプリ管理の写真・一時バックアップ、通知を削除します。内蔵レシピは初期状態に戻り、在庫・買い物は空、通知はOFFになります。途中で失敗した場合は「削除を再試行」を選びます。完了するまで登録・復元はできません。

写真ライブラリの元画像、外部へ保存したファイル、共有商品DBの商品、OS・SDKのキャッシュ、端末の権限は残ります。Web版は現在のブラウザーの同じサイトだけが対象で、他のタブを閉じてから操作してください。読み込みに失敗した場合の復旧画面からも、同じ確認を経て一括削除できます。
