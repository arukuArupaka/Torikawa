## 固定のUnsplash URL

2026-10-20に、新規レシピの画像未設定時・端末内のレシピ候補・開発用食材と商品カタログの固定画像を、既存の食材アイコンへ変更しました。旧サンプル画像のURLは移行時の照合にだけ残します。利用者が以前保存した外部画像を一括削除する処理は入れていません。

[通常ライセンスの公式案内](https://help.unsplash.com/en/articles/2612315-can-i-use-unsplash-images-for-personal-or-commercial-projects)では、通常の画像利用にクレジットを必須としていません。一方、[API経由の表示規定](https://help.unsplash.com/en/articles/2511315-guideline-attribution)には撮影者とUnsplashへの表示・リンク条件があります。固定CDN URLだけでは、作者・元ページ・取得経路・適用条件を確認したことにはなりません。Unsplash+も通常ライセンスと混同しません。

URLごとの過去の参照元と、初期表示から外した状態をJSONに記録しました。以前のバックアップや利用者自身の外部画像の出所を、今回確認したという意味ではありません。

2026-10-14に `src/data/additionalRecipes.v1.json` の92件を、このアプリ用にCodexが独立して作成しました。2026-10-19には、少ない食材・一人分・10分以内の料理20件を `src/data/additionalRecipes.v2.json` に、定番の主菜7件を `src/data/additionalRecipes.v3.json` に、牛丼・餃子など9件を `src/data/additionalRecipes.v4.json` に追加し、既存8件と合わせて内蔵136件になりました。レシピサイトの文章・画像は取り込んでいません。材料と調味料の一覧、分量、人数、手順の整合性を自動確認しますが、味や調理時間の試作検証を行った記録ではありません。

肉の加熱確認は[厚生労働省の家庭での食中毒予防](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/shokuhin/syokuchu/01_00006.html)を参照し、中心温度75℃以上で1分間以上の確認を記載します。食材の傷みや期限を加熱で解決できるという意味ではありません。

2026-10-20に、`src/data/sampleData.ts` の最初の8件と `src/services/localRecipeSuggestionService.ts` の13種の手順を、このアプリ向けに独立して作成し直しました。料理名・材料・分量・人数・分類・目安時間は維持します。レシピサイトの文章や写真を取り込んでいません。

`legacySampleRecipes.v1.json` と `legacySampleRecipes.v2.json` は、古い保存内容と一致するかを判定する比較専用の記録です。旧文章の出所は未確認のままで、新規の表示には使いません。保存済みの内蔵レシピは、手順・材料・分量・名前・分類・時間・人数に編集がない場合だけ更新します。お気に入り・写真・作成日時は保持し、削除済みのレシピは追加し直しません。

## 全136件のAI生成画像

2026-10-14に、追加レシピ `recipe-9`〜`recipe-100` の完成イメージを、Codexの内蔵画像生成機能（image_gen）で料理ごとに作成しました。画像生成APIをアプリから呼び出す機能ではありません。各料理の名前・材料・作り方を指定し、自然光、白い器、木のテーブルで構図をそろえています。

2026-10-19の追加20件と定番の主菜16件も同じ方法で料理ごとに生成しました。保存先は `assets/recipes/generated/recipe-009.jpg`〜`recipe-136.jpg` です。[制作記録と生成指示](../assets/recipes/generated/manifest.json)に、対応する料理、生成指示、日付、画像サイズ、ハッシュを記録しています。元の生成画像を残した上で、アプリ用のJPEGに縮小しています。一人分の20枚は各640×640px、合計約1.37MB、最初の定番7枚は合計約0.51MB、今回の定番9枚は合計約0.76MBです。定番の画像も各640×640pxです。

2026-10-20には最初の8件も生成し、全136件が揃いました。8枚は各640×640px、合計541,667バイトです。内蔵image_genで新規生成し、元PNGを保持した上で配布用JPEGへ縮小しています。最終指示は制作記録の各 `prompt` に残しています。

実際に調理して撮影した写真ではありません。レシピ一覧と詳細で「AI生成のイメージ」と表示します。旧8枚の出所が確認できたという意味ではありません。利用者が設定した写真や編集済みレシピは保持し、追加レシピの未編集の料理アイコンだけを生成画像へ更新します。バックアップには画像そのものを埋め込まず、内蔵画像のIDを保存します。
