# Phase 3：通知と写真付きバックアップ

[READMEへ戻る](../README.md) · [使い方](USAGE.md) · [データ保護と復旧](data-protection.md)

2026-09-29時点で、実装・自動テスト・Web画面確認を実施しました。iOS／Androidの実機間復元と通知の実配信は未確認です。監査レポートのPhase 3受け入れ条件は、下記の実機確認後に完了判定します。

## 通知

- 保存処理と通知予約の更新を待ってから完了を表示し、連打を防ぎます。
- OS上の予約と現在の在庫・設定を照合し、不足分を追加、古い予約や重複を解除します。テスト通知は期限通知と区別します。
- 予約IDを1件ずつ保存します。途中で予約・解除・保存に失敗しても、OS上の識別情報を使って次の同期で復旧します。
- 同期処理を順番に実行し、先の失敗が後の再試行を止めないようにしました。
- 失敗は画面上部に表示し、「通知を再同期」から再試行できます。権限・予約件数の取得失敗も表示します。
- 食材や設定の変更、バックアップ復元、アプリへの復帰時に再同期します。復帰時には権限変更や時刻帯の変更を反映します。
- Webでは非対応と明示し、通知の設定・保存・テストを無効にします。

通知予約の成功は実際の配信を保証しません。OSの予約上限や省電力設定などは実機で確認します。予約が予定と一致しない場合は、成功扱いにせずエラーを表示します。

## 写真とバックアップ

| 項目 | 動作 |
| --- | --- |
| 書き出し前の確認 | 容量・写真枚数・外部画像の件数を表示 |
| 写真の容量 | 1枚5MB、重複を除いた合計10MBまで |
| ファイル全体 | JSONのUTF-8サイズで20MBまで |
| 処理方法 | 画像を順番に読み込み、内容が同じ画像は1つにまとめる |
| 利用者の写真 | 画像データをJSONに含め、復元先で保存する |
| 付属レシピ画像 | 固定IDを保存し、復元先の同梱画像に置き換える |
| 外部画像 | URL参照を保存。表示には通信と公開元での画像の存続が必要 |
| 画像表示の失敗 | 「写真なし」を表示。別の画像へ変更すると再び表示を試す |
| 写真選択の失敗 | エラーを表示して元の写真を保持。再選択可能 |

容量表記の1MBは1,048,576バイトです。選択時はファイル容量に加えて2,400万画素を超える画像も拒否します。容量超過を自動圧縮する機能はありません。

新しいバックアップ形式はv2です。このアプリはv1も読み込めますが、古いアプリはv2を読み込めません。v1も容量制限の対象です。古いバックアップが端末固有の画像パスだけを含む場合、元の画像データを後から復元することはできません。

画像参照の欠落や容量超過はデータの置き換え前に検出します。Phase 1の復元用退避・世代単位の確定処理を引き継いでいます。復元後の通知同期が失敗しても、復元したデータを保持し、通知のみ再試行できます。

## 実機で残る確認

以下はすべて未実施です。実施時にOS・機種・アプリ版・結果を記録してください。

| ケース | 確認する結果 |
| --- | --- |
| iOS→Android、Android→iOSへ復元 | 食材・履歴・レシピ・設定が一致し、利用者の写真と同梱画像を通信なしでも表示できる |
| 外部画像を含む復元 | 通信時に画像を表示し、取得できない場合は「写真なし」になる |
| 通知の配信とタップ | 前面・背面・終了状態で通知を受け取り、対象食材を開ける。削除済みならホームへ戻る |
| 食材の編集・削除・使用・廃棄・取消 | 期限・表示名・管理状態に合った通知だけが残る |
| 設定の変更とバックアップ復元 | 通知日・時刻・ON/OFFが反映され、予約件数と実際の配信が一致する |
| 権限の拒否→許可、許可→拒否 | 復帰後に状態を更新し、必要なエラー表示や再同期ができる |
| 時刻帯の変更 | アプリ復帰後、変更先の時刻帯で指定時刻に通知する |
| 多数の通知予約 | OSの制限に達したとき成功扱いにならず、在庫・設定を調整して再同期できる |
| 写真の権限拒否・選択取消・大きな写真 | 既存の写真と入力内容を保持し、選び直せる |
| 保存先の容量不足・復元中断 | 既存データを失わず、退避・再試行・復旧の案内に沿って戻せる |

参照：[Expo SDK 57](https://docs.expo.dev/versions/v57.0.0/)、[Notifications](https://docs.expo.dev/versions/v57.0.0/sdk/notifications/)、[ImagePicker](https://docs.expo.dev/versions/v57.0.0/sdk/imagepicker/)。
